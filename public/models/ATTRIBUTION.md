# Network cat model attribution

The seated cat mesh in `network-cat.glb` is based on:

- Title: Cat
- Creator: elkiotbear
- Source: https://poly.pizza/m/ovFy5UldDq
- License: Creative Commons Attribution 3.0
- License URL: https://creativecommons.org/licenses/by/3.0/

The model is rendered without its original materials or textures. Its geometry is
merged, welded, tessellated, normalized, and used to generate the node-and-edge
network visualization.
